# 🍳 OFFuncional - Gestão & Ergonomia

> Aplicativo Web Progressivo (PWA) para gestão técnica de equipamentos, conformidade ergonômica e rotinas de higienização em cozinhas profissionais.

---

### 🌐 Acesse o Aplicativo:
👉 **[Clique aqui para abrir o OFFuncional](https://lalinaori.github.io/offuncional/)**

---

## 📱 Funcionalidades Principais

* **Fichas Técnicas de Equipamentos:** Potência, consumo elétrico/gás e exigências de layout/exaustão (Rational, Alfatec).
* **Guia Ergonômico Operacional:** Alturas regulamentares de bancadas, raios de alcance e medidas preventivas antifadiga.
* **Rotinas de Higienização (POP):** Procedimentos operacionais padrão de limpeza, periodicidade e insumos químicos recomendados.
* **Interface Mobile-First:** Simulação responsiva de aplicativo nativo.
* **Instalável (PWA):** Compatível com instalação direta no Android e iOS em tela cheia.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico**
* **CSS3 Moderno** (Layout responsivo com variáveis CSS)
* **JavaScript (Vanilla)** (Filtros dinâmicos e manipulação de DOM)
* **PWA (Progressive Web App)** com Service Worker e Web App Manifest
* **Font Awesome** (Ícones)
